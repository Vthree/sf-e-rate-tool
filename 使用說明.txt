E順遞雙幣拆價運費表－Windows / macOS 使用說明
=================================================

【需要先安裝 Node.js 嗎？】

需要。若要自動從順豐官網同步燃油費及人民幣到付價，必須安裝 Node.js 18 或更新版本。
Node.js 只負責啟動本機同步服務，不需要再安裝 npm 套件。

安裝網址：https://nodejs.org/
請選擇標示為 LTS 的版本。安裝完成後，可在命令提示字元或終端機輸入：

node --version

看到 v18、v20、v22 或更高版本即可。


【Windows 使用方法】

1. 對下載的 ZIP 按右鍵，選擇「全部解壓縮」。
2. 進入解壓縮後的 sf-e-rate-tool 資料夾。
3. 雙擊 start.bat。
4. 若顯示安全警告，確認檔案來自本工具的 GitHub Release 後選擇繼續執行。
5. 瀏覽器會自動開啟本機運費表。
6. 使用期間請保持命令視窗開啟；按 Ctrl+C 可停止服務。

若顯示「找不到 Node.js」，請安裝 Node.js LTS，安裝後關閉並重新開啟工具。


【macOS 使用方法】

1. 雙擊下載的 ZIP 解壓縮。
2. 進入解壓縮後的 sf-e-rate-tool 資料夾。
3. 第一次啟動時，在 start.command 上按右鍵，選擇「打開」，再確認開啟。
4. 之後可以直接雙擊 start.command。
5. 瀏覽器會自動開啟本機運費表。
6. 使用期間請保持終端機視窗開啟；按 Control+C 可停止服務。

若 start.command 無法執行：

1. 開啟「終端機」。
2. 輸入 cd 後加一個空格，把 sf-e-rate-tool 資料夾拖進終端機，再按 Enter。
3. 依序執行：

chmod +x start.command
./start.command


【網址與關閉方法】

預設網址：http://127.0.0.1:4173
若 4173 已被使用，工具會自動改用 4174、4175 等下一個可用連接埠。
關閉命令視窗或終端機，也會停止本機服務。


【沒有 Node.js 時】

可以直接雙擊 index.html 使用內建備援資料計算台幣，但瀏覽器會阻擋跨網域連線，
因此無法同步順豐最新燃油費或人民幣到付價。人民幣欄會顯示「RMB —」，
不會使用台幣乘匯率估算。需要即時同步時，請使用 start.bat 或 start.command。


【人民幣顯示方式】

人民幣不是台幣乘匯率。工具會直接呼叫順豐「運費時效查詢」所使用的官方介面，
取得 E順遞到付價的基本運費、燃油附加費、資源調節費及總運費。

A 區以廣州海珠代表，B 區以北京東城代表；每次寄件日期或小時改變時，工具會查詢
0.5–20 kg 共 80 筆資料。同一寄件時間的成功結果會在本機服務記憶體中快取 6 小時。

每個費用欄以目前應付價為主。只有原價與折後價不同時，才會在下方補充原價。
基本運費及燃油費可以分別設定折扣，折後結果如有小數，一律無條件進位至整數。
資源調節費固定不折扣，因此調節費只顯示一個金額。

未設定折扣時顯示順豐官方人民幣拆價及總價；設定折扣後，才會以官方人民幣拆價
為基礎重算可折扣項目。同步失敗時顯示「—」，不產生匯率估算值。

2026/7/27 官方核對範例：
- 台北 → 廣州海珠，1 kg：33 + 11 + 4 = 48 RMB
- 台北 → 北京東城，1 kg：43 + 14 + 4 = 61 RMB
