# E順遞雙幣拆價運費表

台灣寄往中國大陸的順豐 E順遞運費試算工具，將費用拆分為：

> 基本運費 + 燃油附加費 + 資源調節費 = 總運費

工具為單一 HTML 檔案，不需要安裝程式或啟動本機伺服器，可在 Windows、macOS、手機瀏覽器直接使用。

## 線上使用

[開啟 E順遞雙幣拆價運費表](https://vthree.github.io/sf-e-rate-tool/)

也可以從 [Releases](https://github.com/Vthree/sf-e-rate-tool/releases) 下載 HTML，儲存後直接雙擊開啟。

## 功能

- 僅計算順豐 E順遞，重量範圍為 0.5–20 kg。
- 分開顯示基本運費、燃油附加費、資源調節費及總運費。
- A 區與 B 區使用不同底色，方便辨認目的地區域。
- 支援基本運費、燃油費及調節費各自設定折扣。
- 支援實際重量與材積重量比較，並自動計算計費重量。
- 可選擇預計寄件日期與時間，自動套用內建的每週燃油費率。
- 同時顯示新台幣及人民幣估算，也可切換成單一幣別。
- 可匯出包含 TWD 與 RMB 欄位的 CSV，並支援列印。
- 所有設定及計算都在瀏覽器內完成，不會上傳貨件資料。

## 計算方式

- 材積重量：`長 × 寬 × 高 ÷ 6000`
- 計費重量：實際重量與材積重量取較大者，20 kg 以下以 0.5 kg 進位。
- 人民幣換算預設值：`1 TWD = 0.217286 RMB`。
- 人民幣總價依順豐價格查詢頁面的整數截尾方式估算。

## 資料版本

- E順遞基本運費：2025 年 4 月 1 日版。
- 資源調節費：預設 TWD 20/kg。
- 內建燃油週期：2026/5/11–2026/8/2。
- 最近核對日期：2026/7/27。

單一 HTML 以 `file://` 開啟時，瀏覽器會限制跨網域讀取順豐官網，因此超出內建燃油週期後，請從官方頁面核對並在工具內手動更新燃油費率。人民幣換算率也可直接修改。

## 免責聲明

本工具提供試算參考，不代表順豐正式報價。燃油費、匯率、服務範圍及其他附加費可能隨時調整，實際費用以順豐收件與結算結果為準。
