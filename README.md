# E順遞跨平台雙幣拆價運費表

台灣寄往中國大陸的順豐 E順遞運費試算工具，將費用拆分為：

> 基本運費 + 燃油附加費 + 資源調節費 = 總運費

啟動本機服務後，工具會從台灣順豐官網同步目前公布的燃油費週期，並直接查詢 E順遞「到付價」的人民幣拆價。人民幣不是由台幣乘匯率換算。Windows 與 macOS 都有可直接啟動的檔案。

## 下載

請從 [Releases](https://github.com/Vthree/sf-e-rate-tool/releases) 下載最新跨平台版本。

## 必要條件：Node.js

自動同步版本需要 **Node.js 18 或更新版本**。Node.js 只用來在電腦上啟動本機服務、代替瀏覽器向順豐官網讀取公開資料，不需要安裝其他套件。

安裝方式：

1. 前往 [Node.js 官方網站](https://nodejs.org/)。
2. 下載並安裝標示為 **LTS** 的版本。
3. 安裝完成後關閉並重新開啟命令視窗或終端機。
4. 可輸入 `node --version` 檢查；顯示 `v18`、`v20`、`v22` 或更高版本即可。

若不安裝 Node.js，仍可直接開啟 `index.html` 使用內建備援資料計算台幣；瀏覽器會阻擋跨網域查價，因此人民幣欄只會顯示 `RMB —`，不會用匯率產生估算值。

## Windows 使用方法

1. 安裝 Node.js LTS。
2. 對下載的 ZIP 按右鍵，選擇「全部解壓縮」。
3. 進入解壓縮後的 `sf-e-rate-tool` 資料夾。
4. 雙擊 `start.bat`。
5. 若 Windows 顯示安全警告，確認檔案來自此 GitHub 儲存庫後選擇繼續執行。
6. 瀏覽器會自動開啟 `http://127.0.0.1:4173`；若連接埠已被使用，會自動改用下一個連接埠。
7. 保持命令視窗開啟；按 `Ctrl+C` 可停止服務。

`start.ps1` 會先尋找系統中的 Node.js；若電腦是從 Codex 執行，也會嘗試使用 Codex 內附的 Node.js。

## macOS 使用方法

1. 安裝 Node.js LTS。
2. 雙擊下載的 ZIP 解壓縮。
3. 進入解壓縮後的 `sf-e-rate-tool` 資料夾。
4. 第一次啟動時，在 `start.command` 上按右鍵並選擇「打開」，再確認開啟。
5. 之後可以直接雙擊 `start.command`。
6. 瀏覽器會自動開啟 `http://127.0.0.1:4173`；若連接埠已被使用，會自動改用下一個連接埠。
7. 保持終端機視窗開啟；按 `Control+C` 可停止服務。

如果 `start.command` 失去執行權限，可開啟終端機、輸入 `cd `（後面保留一個空格），將工具資料夾拖進終端機後按 Enter，再執行：

```bash
chmod +x start.command
./start.command
```

## 功能

- 僅計算順豐 E順遞，重量範圍為 0.5–20 kg。
- 分開顯示基本運費、燃油附加費、資源調節費及總運費。
- 啟動時從順豐官網同步目前公布的燃油週期。
- 可選擇預計寄件日期與時間，自動套用對應週期費率。
- A 區與 B 區使用不同底色，方便辨認目的地區域。
- 支援基本運費、燃油費及調節費各自設定折扣。
- 支援實際重量與材積重量比較，並自動計算計費重量。
- 同時顯示新台幣及順豐官方人民幣到付價，也可切換成單一幣別。
- 可匯出包含 TWD 與 RMB 欄位的 CSV，並支援列印。
- 折扣與材積計算都在本機完成；官方人民幣查價只傳送寄件日期／小時、代表路線與重量，不會傳送姓名、電話或地址。

## 自動更新範圍

- 燃油附加費：從順豐官網自動同步，每 15 分鐘最多重新抓取一次。
- 資源調節費：從順豐公告自動核對。
- 基本運費版本：自動檢查官網 E順遞價目表是否換版。
- 人民幣到付價：直接呼叫順豐運費時效查詢所使用的官方介面，分別以廣州海珠（A 區）及北京東城（B 區）查詢 0.5–20 kg 共 80 筆，並在本機快取 6 小時。

若順豐官網無法連線，台幣會改用內建備援燃油週期並清楚顯示警告；人民幣不會退回匯率估算。直接開啟 `index.html` 也可以離線試算台幣，但無法跨網域同步官方人民幣資料。

## 計算方式

- 材積重量：`長 × 寬 × 高 ÷ 6000`
- 計費重量：實際重量與材積重量取較大者，20 kg 以下以 0.5 kg 進位。
- 人民幣原價：直接使用順豐回傳的 `freight`、燃油附加費、資源調節費及 `totalFreight`。
- 人民幣各拆解項目顯示到小數點後一位；未設定折扣時保留順豐官方總價，設定折扣後才依各欄折扣重算。
- 人民幣同步失敗時顯示 `—`，不以台幣或匯率推算。

## 資料版本

- E順遞基本運費：2025 年 4 月 1 日版。
- 資源調節費：預設 TWD 20/kg。
- 內建備援燃油週期：2026/5/11–2026/8/2。
- 官方案例核對：2026/7/27，台北→廣州海珠 1 kg 為 `33 + 11 + 4 = 48 RMB`；台北→北京東城 1 kg 為 `43 + 14 + 4 = 61 RMB`。
