# E順遞跨平台雙幣拆價運費表

台灣寄往中國大陸的順豐 E順遞運費試算工具，將費用拆分為：

> 基本運費 + 燃油附加費 + 資源調節費 = 總運費

啟動本機服務後，工具會從台灣順豐官網同步目前公布的燃油費週期。Windows 與 macOS 都有可直接啟動的檔案。

## 下載

請從 [Releases](https://github.com/Vthree/sf-e-rate-tool/releases) 下載最新跨平台版本。

## Windows 使用方法

1. 安裝 [Node.js 18 或更新版本](https://nodejs.org/)。
2. 解壓縮下載檔。
3. 雙擊 `start.bat`。
4. 瀏覽器會自動開啟本機工具。
5. 保持命令視窗開啟；按 `Ctrl+C` 可停止服務。

`start.ps1` 會先尋找系統中的 Node.js；若電腦是從 Codex 執行，也會嘗試使用 Codex 內附的 Node.js。

## macOS 使用方法

1. 安裝 [Node.js 18 或更新版本](https://nodejs.org/)。
2. 解壓縮下載檔。
3. 雙擊 `start.command`。
4. 瀏覽器會自動開啟本機工具。
5. 保持終端機視窗開啟；按 `Control+C` 可停止服務。

若 macOS 第一次阻擋啟動，請在 `start.command` 上按右鍵並選擇「打開」。如果檔案失去執行權限，可在終端機進入工具資料夾後執行：

```bash
chmod +x start.command
./start.command
```

## 功能

- 僅計算順豐 E順遞，重量範圍為 0.5–20 kg。
- 分開顯示基本運費、燃油附加費、資源調節費及總運費。
- 啟動時從順豐官網同步目前公布的燃油週期。
- 可選擇預計寄件日期與時間，自動套用對應週期費率。
- A 區與 B 區使用不同底色，方便辨認目的地區域。
- 支援基本運費、燃油費及調節費各自設定折扣。
- 支援實際重量與材積重量比較，並自動計算計費重量。
- 同時顯示新台幣及人民幣估算，也可切換成單一幣別。
- 可匯出包含 TWD 與 RMB 欄位的 CSV，並支援列印。
- 所有貨件條件及計算都在本機完成，不會上傳貨件資料。

## 自動更新範圍

- 燃油附加費：從順豐官網自動同步，每 15 分鐘最多重新抓取一次。
- 資源調節費：從順豐公告自動核對。
- 基本運費版本：自動檢查官網 E順遞價目表是否換版。
- 人民幣換算率：使用目前核對的預設值，可在畫面手動修改。

若順豐官網無法連線，工具會改用內建備援燃油週期並清楚顯示警告。直接開啟 `index.html` 也可以離線試算，但無法跨網域同步官方資料。

## 計算方式

- 材積重量：`長 × 寬 × 高 ÷ 6000`
- 計費重量：實際重量與材積重量取較大者，20 kg 以下以 0.5 kg 進位。
- 人民幣換算預設值：`1 TWD = 0.217286 RMB`。
- 人民幣總價依順豐價格查詢頁面的整數截尾方式估算。

## 資料版本

- E順遞基本運費：2025 年 4 月 1 日版。
- 資源調節費：預設 TWD 20/kg。
- 內建備援燃油週期：2026/5/11–2026/8/2。
- 最近人工核對日期：2026/7/27。
